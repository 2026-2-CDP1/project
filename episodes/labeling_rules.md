# 행동 구간 라벨링 규칙 (초안 — 팀 합의 후 확정)

모든 라벨러는 이 규칙만 따른다. 프레임 번호는 **기준 카메라(정면 exo, 에피소드 폴더의 exo.mov)** 영상 **전체** 기준(0부터). 잘린 구간의 상대 번호가 아니다. labels.json 에 exo_start_frame / exo_end_frame(미포함)을 함께 적는다 (`python labels.py init`).

## 에피소드 구간 (exo_start_frame / exo_end_frame)

- 시작: 시작 박수 뒤, **초기 자세로 멈춰 있는 첫 프레임**
- 끝(미포함): 종료 자세에 도달한 프레임 + 1 (끝 박수 전)
- 박수 동작이 구간에 들어가면 안 된다 (4번 리타게팅·6번 데이터셋에 그대로 들어감).

## 행동 구간

| 구간 | 시작 프레임 판정 |
|---|---|
| approach (접근) | 손이 시작 자세에서 움직이기 시작한 첫 프레임 |
| grasp (파지) | 손가락이 물체에 처음 닿은 프레임 |
| transport (운반) | 물체가 테이블에서 떨어진 첫 프레임 |
| release (놓기) | 손가락이 벌어지기 시작한 프레임 |
| retreat (복귀) | 손가락이 물체에서 완전히 떨어진 프레임 |

- `grasp_frame`: 손이 물체를 **완전히 쥔 첫 프레임** (5-2번 파지점 근접 지표가 사용).
- 구간은 겹치지 않고, 각 구간의 end = 다음 구간 start − 1.
- 일관성 확인: 10개 에피소드를 두 사람이 따로 라벨링 → `python labels.py compare A B --tol 3`.
  경계가 tol 프레임 넘게 벌어지는 구간은 판정 문구를 고치고 다시 라벨링.

## 태스크별 끝 상태 (확정 필요)

- **컵 잡기**: 들고 끝나는지, 놓고 끝나는지 아직 정해지지 않았다. 팀 합의 후 여기에 적는다.
  - 들고 끝: transport 까지만 있고 release/retreat 구간은 없다.
  - 놓고 끝: release, retreat 구간이 있다.
  - 구간이 없는 태스크는 labels.json 의 segments 에서 그 구간을 생략한다 (순서는 유지, 인접 구간 end = 다음 start − 1).
- 블록 쌓기, 블록 옮기기: 끝 상태 확정 후 같은 방식으로 적는다.
