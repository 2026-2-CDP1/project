# 동작 구간 표시 안내 (팀원용)

자동으로 동작 구간을 못 나눈 **69개 에피소드**의 시작과 끝을 사람이 표시해요. 손을 테이블 가장자리에 둔 채 박수와 대기를 하면 카메라가 손을 계속 봐서, 자동으로는 박수와 동작을 구분할 수 없어요.

- 할 일: 에피소드마다 시작 사진 1장, 끝 사진 1장 고르기
- 예상 시간: 에피소드당 20~30초 (예상치)
- 결과는 파일로 저장되고, 3번(차서현)이 합쳐요.

## 1. 기준

**이 기준이 제일 중요해요.** 사람마다 다르면 데이터가 달라져요.

창의 `hand=`에 적힌 **작업 손만** 봐요.

| 표시 | 기준 |
|---|---|
| **시작** (`1`) | 박수와 대기가 끝나고, 작업 손이 **테이블 위로 올라오는 첫 사진** |
| **끝** (`2`) | 작업 손이 **테이블에서 내려가기 전 마지막 사진** |

- 박수, 손을 모으고 기다리는 장면은 넣지 않아요.
- 손을 뻗기 직전의 작은 움직임은 넣지 않아요. 손이 테이블 위로 넘어오는 순간부터예요.
- 애매하면 **앞뒤 사진을 비교해서 처음 넘어온 사진**을 골라요. 사진은 0.2초 간격이라 한 장 차이는 괜찮아요.
- 어떤 장면이 동작인지 정말 알 수 없으면 `x`를 누르고, 에피소드 번호를 3번에게 알려 주세요.

## 2. 내 담당 확인

3번에게 **이름**과 **번호**를 받아요. 예를 들어 3명이 나누면 `1/3`, `2/3`, `3/3` 중 하나예요.

| 담당 | 이름 (`--name`, 영문) | 번호 (`--part`) |
|---|---|---|
| | | |
| | | |
| | | |

저장 파일은 이름별로 따로 생겨서 서로 덮어쓰지 않아요. **이름은 끝까지 같게** 쓰세요.

## 3. 준비 (처음 한 번)

Python 3과 아래 패키지가 필요해요.


서버에서 사진을 받고 코드를 받아요. 서버 비밀번호는 팀 공유 방법으로 확인하세요. 사진은 약 3,500장이고 몇 분 걸려요.

```bash
scp -P 10000 -r coss37@155.230.81.91:~/out/seohyeon/seg_frames ~/Downloads/
git clone -b episodes/process-all https://github.com/2026-2-CDP1/project cdp1-project
```

이미 레포가 있으면 `git clone` 대신 해당 브랜치를 받으면 돼요.

서버 접속이 막히면 핫스팟으로 바꿔 보세요. **서버의 `~/out/seohyeon/` 안 파일은 지우거나 고치지 마세요.**

## 4. 표시

```bash
cd cdp1-project/episodes/tools
python3 seg_click.py click --frames ~/Downloads/seg_frames --name 내이름 --part 1/3
```

창의 왼쪽은 정면 카메라, 오른쪽은 작업 손 쪽 카메라예요. 아래 막대에 지금 위치와 표시가 보여요.

| 키 | 동작 |
|---|---|
| `d` / `a` | 다음 / 이전 사진 (0.2초) |
| `e` / `w` | 5장 앞 / 뒤 |
| `1` | 지금 사진을 **시작**으로 (초록) |
| `2` | 지금 사진을 **끝**으로 (빨강) |
| `s` | 저장하고 다음 에피소드 |
| `b` | 이전 에피소드 |
| `x` | 알 수 없음으로 저장하고 다음 |
| `q` | 끝내기 |

**순서:** 사진을 넘겨 시작 사진에서 `1` → 끝 사진에서 `2` → `s`.

- `q`로 꺼도 저장한 곳부터 이어서 시작해요.
- 잘못 표시했으면 `b`로 돌아가 다시 `1`, `2`, `s`를 누르면 덮어써요.
- 시작과 끝을 다 찍어야 `s`가 돼요.

**키가 안 먹으면** 입력기를 영문으로 바꾸고 창을 한 번 클릭하세요.

## 5. 기준 맞추기 (시작 전에 모두)

사람마다 기준이 다른지 보려고, **모두 같은 3개를 먼저 표시**해요.

```bash
python3 seg_click.py click --frames ~/Downloads/seg_frames --name 내이름 --ids T2_E010 T2_E030 T3_E053
```

끝나면 3번에게 파일을 보내고, 차이가 크면 맞춘 뒤에 담당 분량을 시작해요.

## 6. 끝나면

담당 분량을 다 표시하면 도움말의 `done` 숫자를 확인하고, 저장 파일을 3번에게 보내요.

```
~/Downloads/seg_frames/seg_marks_내이름.json
```

**이 파일이 작업 결과예요.** 사람이 직접 만든 값이니 지우지 마세요.

## 3번(차서현)이 합치는 방법

받은 파일을 `episodes/`에 모아 커밋한 뒤, 서버에서 합쳐요.

```bash
python seg_click.py merge --segments ~/out/seohyeon/segments.csv --marks ../seg_marks_*.json --out ~/out/seohyeon/segments_final.csv
```

- 같은 에피소드를 두 사람이 표시했으면 프레임 차이가 출력돼요. 이걸로 **사람 사이 차이**를 확인해요. T1·T3는 60 fps, T2는 30 fps라 같은 프레임 수도 시간은 달라요.
- `빠짐`에 나온 에피소드는 아직 표시되지 않은 거예요.
