# 파지 프레임 표시 안내 (팀원용)

손이 물체를 **쥔 순간의 사진 1장**을 에피소드마다 고르는 작업이에요. 이 값은 파지점 거리 지표와 재생 영상 표시에 쓰여요.

- 할 일: 에피소드마다 사진 1장 고르기 (사진 간격 0.1초)
- 결과: 내 컴퓨터에 파일 하나가 생기고, 그 파일을 차서현에게 보내요.

## 2. 기준

창에 적힌 `hand=`의 **작업 손만** 봐요.

> 작업 손이 물체를 **완전히 쥔 첫 사진**. 여러 번 잡으면 **첫 번째만**.

| 태스크 | 고르는 사진 |
|---|---|
| 컵 잡기 | 손가락이 컵을 감싸 다 닫힌 첫 사진 (들어 올리기 전이나 직전) |
| 블록 쌓기, 블록 옮기기 | 손가락이 블록을 집어 다 닫힌 첫 사진 |

- 처음 닿은 사진이 아니라 **다 쥔** 사진이에요.
- 물체가 움직이기 시작했다면 이미 쥔 거예요. 애매하면 그 바로 앞 사진을 골라요.
- 정면에서 가려지면 오른쪽 칸(작업 손 쪽 카메라)을 봐요.
- 끝까지 알 수 없으면 `x`를 누르고, 에피소드 번호를 차서현에게 알려 주세요.

## 4. 표시

```bash
cd cdp1-project/episodes/tools
python3 grasp_click.py click --frames ~/Downloads/grasp_frames_1 --name 내이름
```

| 키 | 동작 |
|---|---|
| `d` / `a` | 다음 / 이전 사진 (0.1초) |
| `e` / `w` | 5장 앞 / 뒤 |
| `1` | 지금 사진을 **파지 프레임으로** (초록) |
| `s` | 저장하고 다음 에피소드 |
| `b` | 이전 에피소드 |
| `x` | 알 수 없음으로 저장하고 다음 |
| `q` | 끝내기 |

**순서:** 사진을 넘겨 쥔 순간에서 `1` → `s`

- `q`로 꺼도 같은 명령으로 다시 켜면 이어서 시작해요.
- 잘못 표시했으면 `b`로 돌아가 다시 `1`, `s`를 누르면 덮어써요.
- **키가 안 먹으면** 입력기를 영문으로 바꾸고 창을 한 번 클릭하세요.
