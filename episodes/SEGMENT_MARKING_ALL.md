# 동작 구간 표시 안내 (나머지 155개)

영상에서 **동작 구간의 시작과 끝**을 사람이 고르는 작업이에요. 박수와 대기 장면을 빼기 위해서예요. 세 명이 나눠서 해요.

- 할 일: 에피소드마다 시작 사진 1장, 끝 사진 1장 고르기
- 결과: 내 컴퓨터에 파일 하나가 생기고, 그 파일을 차서현에게 보내요.

## 2. 기준

**이 기준이 제일 중요해요.** 사람마다 다르면 데이터가 달라져요.

창에 적힌 `hand=`의 **작업 손만** 봐요.

| 표시 | 기준 |
|---|---|
| **시작** (`1`) | 박수와 대기가 끝나고, 작업 손이 **테이블 위로 올라오는 첫 사진** |
| **끝** (`2`) | 작업 손이 **테이블에서 내려가기 전 마지막 사진** |

- 박수, 손을 모으고 기다리는 장면은 넣지 않아요.
- 애매하면 앞뒤 사진을 비교해서 **처음 넘어온 사진**을 골라요. 사진은 0.2초 간격이라 한 장 차이는 괜찮아요.
- 동작을 정말 알 수 없으면 `x`를 누르고, 에피소드 번호를 차서현에게 알려 주세요.

## 3. 준비 (처음 한 번)

서버 접속이 안 되면 핫스팟으로 바꿔 보세요. 서버의 `~/out/seohyeon/` 안 파일은 **지우거나 고치지 마세요.**

## 4. 표시

`seg_frames_a`와 `내이름`을 바꿔서 실행해요.

```bash
cd cdp1-project/episodes/tools
python3 seg_click.py click --frames ~/Downloads/seg_frames_a --name 내이름
```

창의 왼쪽은 정면 카메라, 오른쪽은 작업 손 쪽 카메라예요. 아래 막대에 지금 위치와 표시가 보여요.

| 키 | 동작 |
|---|---|
| `d` / `a` | 다음 / 이전 사진 (0.2초) |
| `e` / `w` | 5장 앞 / 뒤 |
| `1` | 지금 사진을 **시작**으로 (초록) |
| `2` | 지금 사진을 **끝**으로 (빨강) |
| `s` | 저장하고 다음 에피소드 |
| `b` | 이전 에피소드 |
| `x` | 알 수 없음으로 저장하고 다음 |
| `q` | 끝내기 |

**순서:** 시작 사진에서 `1` → 끝 사진에서 `2` → `s`

- `q`로 꺼도 같은 명령으로 다시 켜면 이어서 시작해요.
- 잘못 표시했으면 `b`로 돌아가 다시 `1`, `2`, `s`를 누르면 덮어써요.
- 시작과 끝을 다 찍어야 `s`가 돼요.
- **키가 안 먹으면** 입력기를 영문으로 바꾸고 창을 한 번 클릭하세요.
