# 구간별 exo 보정 파일

촬영 중 카메라가 움직인 구간의 보정값이에요. 그 구간을 찍은 체커보드 영상이 없어서, 손 키포인트로 다시 구했어요 (`tools/recalib.py`). 형식은 `sync/exo_calib_T{n}.json`과 같아요.

| 에피소드 | 보정 파일 |
|---|---|
| T1 E001~E016 | `sync/exo_calib_T1.json` |
| **T1 E017~E075** | **`episodes/calib/exo_calib_T1_E017.json`** |
| T2 E001~E069 | `sync/exo_calib_T2.json` |
| **T2 E070~E075** | **`episodes/calib/exo_calib_T2_E070.json`** |
| T3 E001~E075 | `sync/exo_calib_T3.json` |

코드에서는 `tools/io_utils.find_calib("<sync 폴더>", "T1_E040")`로 고르면 돼요.

## 무엇이 움직였나

에피소드마다 배경 특징점을 그 태스크의 E001과 비교해 쟀어요. front는 전 구간 거의 그대로예요.

- **T1 E017부터:** exo_right 약 (+198, +20) px, 약 4° 기울어짐. exo_left 약 10~45 px (측정 잡음 큼)
- **T2 E070부터:** exo_left 약 +33 px
- T2 E054~E069, T3 E052~E075: exo_left 약 12 px. 다시 구해도 이득이 거의 없어서 원본을 그대로 써요.

## 검증 (계산에 안 쓴 에피소드)

| 파일 | 3대 모두 사용 (원본 → 새 값) | 오차 중앙값 (원본 → 새 값) |
|---|---|---|
| `exo_calib_T1_E017.json` | 0.0 → 0.524 | 2.87 → 5.26 px |
| `exo_calib_T2_E070.json` | 0.215 → 0.869 | 5.95 → 8.87 px |

- 원본의 오차가 더 작은 건 대부분 2대로 줄인 결과라서예요. 2대는 위치가 틀려도 오차가 작게 나올 수 있어요.
- T1 이동 전 구간(E001~E016, 원본)은 3대 모두 사용 0.534, 오차 4.49 px예요.
- T1은 장애물 박스를 세 카메라에 그려서도 확인했어요.

## 한계

- 체커보드보다 정밀하지 않을 수 있어요. 손이 움직이는 공간에서 맞춘 값이에요.
- T1 right는 배경 실측과 비교해 세로 이동 24 px, 회전 1.6° 차이가 있어요.
- T1 left와 T2 left는 위치를 고정하고 방향만 풀었어요. 실제 위치도 조금 바뀌었다면 그만큼 오차가 남아요.
- T2 E070~E075는 검증 점이 130개로 적고, 장애물 사진이 없어 숫자로만 확인했어요.
