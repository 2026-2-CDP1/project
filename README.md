# 리타게팅 알고리즘 비교 연구

경북대 SW중심대학 산학협력 프로젝트 (크라우드웍스)

## 프로젝트 소개

사람의 손 작업 영상(ego/exo)에서 손 궤적을 뽑아 로봇 팔로 옮기는 **리타게팅 알고리즘 여러 개를 같은 조건에서 비교**하는 프로젝트입니다.
알고리즘별 로봇 궤적을 시뮬레이터에서 재생해 지표(관절 한계 위반, 자기 충돌, 저크, 파지점 거리 등)로 평가하고, 가장 나은 알고리즘의 궤적으로 **OpenVLA를 LoRA 학습**한 뒤 오프라인 평가까지 진행합니다.

```
촬영·싱크 → 수집·가공 → 리타게팅 → 궤적 재생·지표 계산 → VLA 데이터셋 변환 → OpenVLA LoRA 학습 → 평가
```

## 폴더 구조

```
project/
├── robot/       # 1. 로봇·시뮬레이터 셋업 — 팔 모델(URDF/MJCF), 관절 한계표
├── sync/        # 2. 촬영 프로토콜·싱크 — 촬영 절차, 카메라 보정, 싱크 표
├── episodes/    # 3. 수집·가공 — 에피소드별 영상, 키포인트, 라벨, 메타데이터
├── retarget/    # 4. 리타게팅 — 알고리즘별 관절 궤적 (A_DLS, B_mink, C_ikgeo, D_pyroki)
├── replay/      # 5-1. 궤적 재생 — 시뮬레이터 재생 코드, 나란히 보기 영상
├── metrics/     # 5-2. 지표 계산 — 지표 정의서, 계산 코드, 결과 표
├── rlds/        # 6. VLA 데이터셋 변환 — RLDS 변환 코드
├── runs/        # 7. OpenVLA LoRA 학습 — 학습 설정, 로그
└── eval/        # 8. Offline 평가 — 평가 코드, 결과
```

## 공통 규칙

- **에피소드 ID**: `T{태스크번호}_E{세 자리 번호}` (예: `T2_E017`)
- **단위**: 길이 m, 각도 rad, 시간 s
- **쿼터니언**: (w, x, y, z) 순서
- **설정과 지표 정의는 결과를 보기 전에 고정**합니다.

## 대용량 파일

영상(mp4 등), npy/npz, 체크포인트는 `.gitignore`로 제외하고 공유 드라이브에 같은 폴더 구조로 둡니다.
