# OpenVLA LoRA 학습 (`knu_retarget`)

| 파일 | 하는 일 | 상태 |
|---|---|---|
| `smoke_knu.sh` | 우리 RLDS로 50스텝 학습 점검 | 2026-11-06 통과 |
| `train_knu.sh` | 본 학습 20,000스텝 (2,000스텝마다 체크포인트) | 최종 C 결과 대기 |

순서: `rlds/run_convert.sh`(변환) → `rlds/build.py`(RLDS) → `rlds/check_rlds.py`(점검) → `smoke_knu.sh` → `train_knu.sh`
OpenVLA에는 먼저 `rlds/openvla/apply_patch.sh`로 패치를 적용해 둔다.

## 50스텝 점검 결과 (2026-11-06, C 리허설 결과 84개)
| 항목 | 결과 |
|---|---|
| 시작·종료 | 50스텝 2분 42초, 체크포인트 저장 정상 (확인 후 삭제) |
| 손실 | 3.72 → 2.85 (L1 0.33 → 0.14) |
| 데이터 | 에피소드 84, 전이 5,595 (`dataset_statistics.json`) |
| 정규화 마스크 | action `[True] * 7` → 7번 관절도 정규화됨 |
| 행동 범위 (1~99%) | q01 `[-1.72, -2.09, -2.35, -2.09, -2.68, -2.09, -2.79]`, q99 `[2.04, 2.09, 2.44, 2.09, 2.74, 2.09, 2.61]` |

관절 2·4·6의 범위가 관절 한계(±2.094 rad)와 같다. C 결과에 한계에 붙은 프레임이 많다는 뜻이라 4번(리타게팅)에 공유했다 (`rlds/knu_retarget/README.md`).

## 본 학습 전에 할 것
1. 최종 C 결과로 변환 → RLDS → 점검을 다시 한다 (지금 RLDS는 박수 구간 기준 리허설 결과)
2. 저장 공간 약 150 GB 확인, GPU 사용 시간대(약 하루)를 팀에 공유
3. 학습 후: 체크포인트 목록, `dataset_statistics.json` 위치, **가운데 자르기(`image_aug True`로 학습)**, 추론 코드를 8번(평가)에 전달
